# Система мониторинга криптовалютных операций с применением ИИ

Платформа для отслеживания подозрительных операций с криптовалютой. Помогает аналитику
быстро отвечать на вопросы: какие операции требуют внимания, какие кошельки ведут себя
подозрительно, какие транзакции стоит проверить в первую очередь.

Первая версия работает с блокчейном **Ethereum** (данные через Etherscan API).

## Принцип проекта

Сначала строится платформа мониторинга, затем добавляется искусственный интеллект.
ИИ — один из инструментов внутри системы, а не её единственная ценность.

```
Получение данных (Ethereum)
      ↓
   База данных
      ↓
 Расчёт риска (Rule Engine)
      ↓
   Оповещения (Alerts)
      ↓
 Интерфейс аналитика
      ↓
 Модуль ИИ (AI Engine)  ← добавляется на втором этапе
```

## Стек технологий

- **Python** — анализ данных и реализация моделей
- **scikit-learn** — машинное обучение на старте (возможен переход на PyTorch)
- **pandas** — обработка данных
- **PostgreSQL** — база данных
- **Etherscan API** — получение транзакций Ethereum (через слой-адаптер, заменяемый на свой RPC-узел)
- **Elliptic Dataset** — размеченный датасет для обучения модели
